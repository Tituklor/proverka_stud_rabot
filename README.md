#  Система автоматизированной предварительной проверки студенческих работ

##  Описание проекта
Данный репозиторий содержит курсовой проект по разработке клиент-серверной информационной системы для автоматизированной предварительной проверки студенческих работ (курсовых, эссе). 

Система берет на себя рутинную проверку оформления (нормоконтроль по ГОСТ) и анализ на оригинальность (антиплагиат). **Важная особенность:** система не заменяет преподавателя и не выставляет оценки. Её задача — отфильтровать работы с техническими ошибками и предоставить студенту мгновенную обратную связь для доработки.

## Практическая значимость
* **Для преподавателей:** Освобождает до 40% времени, которое обычно тратится на проверку полей, шрифтов и структуры. Преподаватель получает уже отформатированную работу и может сосредоточиться на оценке её научной ценности.
* **Для студентов:** Механизм мгновенной обратной связи. Студент видит конкретные ошибки (например, «неверный отступ на стр. 14» или «оригинальность 62%») и может исправить их до итоговой защиты.
* **Для вуза:** Снижает процент работ, отклоненных на предзащите из-за банальных ошибок оформления.

##  Роли пользователей
1. **Студент:** Загружает файлы, отслеживает статус, получает детальные отчеты об ошибках и загружает исправленные версии.
2. **Преподаватель:** Получает доступ только к работам, успешно прошедшим автопроверку. Изучает содержание, выставляет оценку и пишет рецензию.
3. **Администратор:** Управляет базой знаний (правила ГОСТ, требования вуза), учетными записями и настраивает параметры проверки (пороги антиплагиата).

## Архитектура системы
Система построена по клиент-серверному принципу:
* **Клиентская часть:** Нативное десктопное приложение (UI) для взаимодействия с пользователями.
* **Серверная часть:** Удаленная вычислительная машина, на которой выполняются тяжелые процессы парсинга, логического вывода и анализа текстов.

##  Основные подсистемы
1. **Подсистема хранения базы знаний:** Хранение и версионирование формализованных правил оформления.
2. **Парсер документов:** Извлечение фактов из файлов (docx, pdf, txt) — стили, метаданные, структура.
3. **Модуль Антиплагиат:** Сравнение текста с внутренней базой вуза и внешними источниками.
4. **Модуль Проверки оформления:** Сопоставляет извлеченные факты с правилами из базы знаний с использованием продукционных правил и логического вывода.
5. **Решатель задач (Машина вывода):** Сопоставление фактов от парсера с правилами из базы знаний (продукционные правила).
6. **Генератор отчетов:** Формирование понятного отчета с трассировкой вывода, указанием страниц и абзацев.
7. **Интерфейсный слой:** Нативный UI для загрузки файлов и отображения результатов.
8. **Подсистема хранения данных:** Базы данных для работ, пользователей и истории проверок.
